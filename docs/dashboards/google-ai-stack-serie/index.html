Vorspann

Drei Oberflächen, eine Logik

Google hat seine Entwickler-Werkzeuge rund um Gemini neu sortiert: Antigravity 2.0 ist das Agenten-Cockpit auf dem Desktop, AI Studio der Browser-Playground mit API-Key-Verwaltung, Colab das Rechenlabor mit kostenloser GPU. Alle drei sprechen dieselbe Sprache: Prompt → Agent → Tools via MCP → Code / Notebook. Diese Serie zeigt, was heute wirklich geht – mit Blick auf Statik-, LCA- und Dokumentations-Workflows im Ingenieurbüro.

Kurzfassung (TL;DR)

  • Ein API-Key aus AI Studio reicht für Playground, Colab und eigene Skripte (Python google-genai, JS @google/genai).
  • MCP (Model Context Protocol) ist der Steckplatz: ein JSON-Eintrag in mcp_config.json verbindet GitHub, Colab, Docs-Server & Co. mit dem Agenten.
  • Antigravity 2.0 liest diese Konfiguration global (~/.gemini/config/mcp_config.json) oder pro Projekt (.agents/mcp_config.json, committbar).
  • Der Colab-MCP-Server (Apache 2.0) lässt den Agenten Notebooks anlegen, Zellen schreiben und ausführen.
  • Keys gehören nie in Chat, Zelle oder Repo – nur in .env, Colab-Secrets oder die App-Settings.

Teil 2

AI Studio: API-Key in drei Minuten

AI Studio ist der schnellste Einstieg: Modell wählen, Prompt testen, Temperatur drehen, JSON-Schema erzwingen – und per „Get Code“ den fertigen Python- oder JavaScript-Aufruf mitnehmen.

  1. aistudio.google.com öffnen, mit Google-Konto anmelden.
  2. Links Get API key bzw. direkt aistudio.google.com/api-keys → Create API Key. Der Key beginnt mit AIzaSy…; sofort in Passwort-Manager oder .env.
  3. Playground: Modell (z. B. gemini-3.5-flash, gemini-3.8-flash, gemini-3.1-pro-preview), System Instruction, Temperature, Structured Output, Function Calling.
  4. Oben rechts Get code <>: System-Prompt, Schema und Parameter wandern in den Code-Export (Python/JS/cURL).

Minimaltest per cURL

export GEMINI_API_KEY="YOUR_API_KEY"
curl "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "x-goog-api-key: $GEMINI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"contents":[{"parts":[{"text":"Summarize ISO 20887 DfD principles in 5 bullets for a slide."}]}]}'

Python: ein Client, ein Aufruf

pip install google-genai

from google import genai
client = genai.Client()                      # liest GEMINI_API_KEY aus der Umgebung
r = client.models.generate_content(
    model="gemini-3.5-flash",
    contents="Summarize ISO 20887 DfD principles in 5 bullets for a slide.")
print(r.text)

JavaScript/TypeScript: @google/genai

npm install @google/genai

import { GoogleGenAI } from '@google/genai';
const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });
const r = await ai.models.generateContent({
  model: 'gemini-3.5-flash',
  contents: 'Explain ISO 20887 DfD in 5 bullets for a slide'
});
console.log(r.text);

Stolpersteine

  • Das alte Paket @google/generative-ai ist abgekündigt – nur noch @google/genai verwenden (ein SDK für Developer-API und Vertex AI).
  • Das JS-SDK kann MCP-Tools direkt einbinden (mcpToTool, experimentell) und bietet die Live-API (Audio/Video-Streams).
  • In AI Studio erzeugte Keys sind auf die Generative Language API beschränkt – gut so. Auf der Key-Seite nach „unrestricted“-Hinweisen prüfen.

Maschinenlesbare Docs für Agenten

  • aistudio.google.com/llms.txt – Index aller Doc-Seiten (jede Seite auch als .md, z. B. /docs/function-calling.md, /docs/structured-output.md).
  • llms-full.txt – gesamte Doku in einer Datei (für Context-Caching/RAG).
  • Gemini Docs MCP-Server: https://gemini-api-docs-mcp.dev – Live-Suche in der Gemini-Doku aus Claude Code, Cursor, Antigravity.
  • SDK-Repos: googleapis/python-genai, googleapis/js-genai.
Teil 3

Colab: Rechenlabor mit Agenten-Anschluss

Colab ist Jupyter ohne Installation – und seit 2026 mit einem offiziellen MCP-Server, über den ein Agent Notebooks anlegt, Zellen schreibt und auf CPU oder T4-GPU ausführt.

Secrets statt Klartext

Links in der Seitenleiste das Schlüssel-Symbol → Add Secret, Name exakt GEMINI_API_KEY, „Notebook access“ einschalten. Notebooks werden geteilt – ein Key in einer Zelle ist ein Key im Netz.

from google.colab import userdata
import os
os.environ['GEMINI_API_KEY'] = userdata.get('GEMINI_API_KEY')  # aus Colab-Secrets, nie in der Zelle

Beispiel: LCA-Tabelle Masse × GWP-Faktor

import pandas as pd
import matplotlib.pyplot as plt

# Bauteil, Masse [kg], GWP-Faktor A1-A3 [kgCO2e/kg] – Platzhalter, durch EPD-Werte ersetzen
df = pd.DataFrame({
    'element': ['CLT wall', 'Concrete slab', 'Steel beam', 'Glulam beam'],
    'mass_kg': [12000.0, 45000.0, 3000.0, 6500.0],
    'gwp_kgco2e_per_kg': [-0.60, 0.11, 1.50, -0.55],   # negativ = biogener Kohlenstoffspeicher
})
df['gwp_kgco2e'] = df['mass_kg'] * df['gwp_kgco2e_per_kg']
total = df['gwp_kgco2e'].sum()

ax = df.plot.bar(x='element', y='gwp_kgco2e', legend=False)
ax.axhline(0, color='k', lw=0.8)
ax.set_ylabel('GWP A1–A3 [kgCO2e]'); ax.set_title(f'Tallinn LCA – Summe {total:,.0f} kgCO2e')
plt.tight_layout(); plt.show()

Structured Output: Absolut-Behauptungen in Folien finden

from pydantic import BaseModel
class Claim(BaseModel):
    slide: int
    text: str
    absolute: bool   # "0 %", "infinite", "no glue" …

r = client.models.generate_content(
    model="gemini-3.5-flash",
    contents="Slide 3: Our CLT wall has 0% waste and infinite reuse. Slide 4: Screws only, no glue.",
    config={"response_mime_type": "application/json", "response_schema": list[Claim]})
print(r.text)   # → JSON-Liste, direkt weiterverarbeitbar

Colab-MCP: Der Agent bedient das Notebook

Google stellt den Server unter github.com/googlecolab/colab-mcp (Apache 2.0) bereit. Er verbindet einen lokalen Agenten mit einer Colab-Sitzung im Browser; der Client muss notifications/tools/list_changed unterstützen (Gemini CLI, Claude Code, Windsurf, Antigravity).

pip install uv
# Eintrag in mcp_config.json (Antigravity) bzw. mcp.json (andere Clients):
"colab-mcp": {
  "command": "uvx",
  "args": ["git+https://github.com/googlecolab/colab-mcp"],
  "timeout": 30000
}

Achtung bei Colab-MCP

  • Auth läuft über den Browser (Google-Login); der Scope umfasst Drive-Zugriff – mit Bedacht freigeben.
  • Agenten-Code läuft sichtbar in der Colab-Sitzung: keine Secrets in Zellen ausführen lassen.
  • Tool-Namen und Token-Pfad (im Umlauf: „7 Tools“, create_notebook, add_cell, execute_cell) stehen nicht auf der README-Startseite → beim ersten Connect mit /mcp bzw. Tool-Liste prüfen.

Alternative: Datalayer Jupyter-MCP (hosted)

Endpunkt https://mcp.datalayer.run/mcp – ein Server für beliebige Notebooks inklusive Colab-Sandbox-Variante. Aus unserer Testumgebung war der Endpunkt nicht erreichbar (Client-Fehler); Tool-Umfang und Scopes daher ungeprüft.

Antigravity 2.0: Konfiguration, Plugins, GitHub

Die App, die IDE und die CLI agy teilen sich eine zentrale MCP-Konfiguration. Wer sie einmal sauber aufsetzt, hat seine Werkzeuge in allen drei Oberflächen.

Installation

# Desktop-App: https://antigravity.google/download  (macOS 12+, Windows 10+, Linux glibc ≥ 2.28)
# CLI (macOS/Linux):
curl -fsSL https://antigravity.google/cli/install.sh | bash
# CLI (Windows PowerShell):
irm https://antigravity.google/cli/install.ps1 | iex

agy --help
agy plugin list

Wo die Konfiguration liegt

In der App: Agent-Panel → … → MCP Servers öffnet den MCP-Store; „Copy Config File Path“ führt zur Rohdatei. In der CLI zeigt /mcp die verbundenen Server.

Fertige mcp_config.json (Starter)

{
  "mcpServers": {
    "github": {
      "serverUrl": "https://api.githubcopilot.com/mcp/",
      "headers": { "Authorization": "Bearer ${GITHUB_PAT}" },
      "enabledTools": ["search_code","get_file_contents","list_issues","create_issue",
                       "list_pull_requests","get_pull_request","search_repositories"],
      "timeout": 180000
    },
    "colab-mcp": {
      "command": "uvx",
      "args": ["git+https://github.com/googlecolab/colab-mcp"],
      "timeout": 30000
    },
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"],
      "env": { "CONTEXT7_API_KEY": "${CONTEXT7_API_KEY}" }
    },
    "gemini-api-docs": { "serverUrl": "https://gemini-api-docs-mcp.dev" }
  }
}

Tipps zur Konfiguration

  • GitHub-MCP hat die größte Tool-Fläche (~80 Tools) → mit enabledTools/disabledTools beschneiden. Für den Start: Read-Only-Endpunkt https://api.githubcopilot.com/mcp/readonly – null Mutationsrisiko.
  • serverUrl + headers für gehostete Server, command + args + env für lokale Prozesse. Timeout-Default 3 Minuten.
  • Credentials bleiben lokal; jeder MCP-Tool-Aufruf fragt standardmäßig um Freigabe.

Plugin-Marketplace (seit 29.10.2026)

Ein Plugin bündelt bis zu fünf Teile: Skills, MCP-Server, Rules, Hooks, Custom Agents – ein Install, ein Update, ein Schalter. Launch-Partner u. a. Atlassian, Figma, Linear, Notion, Stripe, monday.com.

agy plugin install figma                                 # offizieller Katalog
agy plugin install https://github.com/<owner>/<repo>      # beliebiges Repo
agy plugin install ./my-plugin                           # lokaler Ordner
agy plugin list | enable | disable | uninstall <name>

  "name": "eder-zotter-tools", "description": "Statik + LCA Werkzeuge" }

  • „Verified“ im Marketplace heißt: von Google gelistet – das Prüfverfahren ist nicht veröffentlicht.

Teil 5

Praxis: Automatisierung, Daten, Visualisierung, Interaktion

Was lässt sich mit diesem Stack heute grundsätzlich abdecken? Eine Bestandsaufnahme entlang der vier Fragen, die im Ingenieurbüro zählen.

Automatisierung

  • Antigravity: mehrere Agenten parallel, Scheduled Tasks, Artifacts pro Projekt.
  • agy in Shell/CI: Skripte, Hooks (pre-invocation), Plugins mit Rules.
  • Gemini Function Calling + Structured Output = deterministische Schnittstelle zu eigenen Python-Solvern (EC2/EC5).
  • Built-in Tools der Gemini-API: Google Search, Code Execution, Live-API.

Datenintegration

  • MCP als Universal-Adapter: GitHub, Drive (via Colab-OAuth), BigQuery, Notion, Jira, Figma.
  • Colab liest Drive-Dateien direkt (drive.mount) – CSV/XLSX → pandas.
  • Context7 / Docs-MCP: aktuelle Library- und API-Doku in den Kontext, statt veraltetes Modellwissen.
  • 1-Mio-Token-Kontext (Gemini 3 Flash/Pro): ganze Normkapitel oder Statikberichte in einem Prompt.

Visualisierung

  • Colab: matplotlib/plotly, T4-GPU für größere Modelle; Plots direkt im Notebook.
  • Antigravity-Artifacts: Agent erzeugt Diagramme, HTML-Dashboards, Reports als Projektartefakte.
  • Structured Output → JSON → beliebiges Frontend (Three.js, Pyodide-Dashboards).

Benutzerinteraktion

  • AI Studio Playground: System-Prompt und Schema interaktiv testen, dann „Get Code“.
  • Antigravity App: Chat + Approval je Tool-Call (Human-in-the-loop by default).
  • Live-API (ai.live): Sprache/Video in Echtzeit – Baustellen-Assistent denkbar.
  • JS-SDK + mcpToTool: eigene Web-UI mit MCP-Werkzeugen.

Beispiel-Workflow: Folien auf Absolut-Behauptungen prüfen

  1. Projekt in Antigravity öffnen (Ordner mit den Tallinn-Folien), .agents/mcp_config.json mit GitHub-MCP + Docs-MCP anlegen.
  2. Agent-Task: „Check all slides for absolute claims (0 %, infinite, no glue); list file + line; cite ISO 20887 via Docs-MCP.“
  3. Ergebnis als Artifact (Markdown-Tabelle) → per GitHub-MCP als Issue ins Repo.
  4. Für die Zahlen: Agent lässt via Colab-MCP das LCA-Notebook laufen und hängt den Plot an.
Teil 6

Für Vibe Coder, Prompter und Hobby-Programmierer: Nachbauen in einem Abend

Kein Informatikstudium nötig. Wer Prompts schreiben kann, baut mit diesem Stack eigene Web-Dashboards – der Agent tippt, du steuerst. Hier die Rezepte, die ohne Setup-Frust funktionieren.

Lernpfad (3 Abende)

  • Abend 1: AI Studio → Key → Playground → „Get Code“ → in Colab laufen lassen. Ziel: erster eigener Gemini-Aufruf.
  • Abend 2: Colab-Notebook mit Daten (CSV aus Drive) → Plot → Structured Output als JSON. Ziel: Daten rein, Tabelle + Grafik raus.
  • Abend 3: Antigravity installieren, mcp_config.json einspielen, Agent eine HTML-Seite mit Chart bauen lassen. Ziel: eigenes Web-UI-Dashboard.

Web-UI-Dashboard-Rezepte (Single-File HTML)

  • Pyodide: Python im Browser – pandas + matplotlib ohne Server; ideal für Rechen-Tools (Statik, LCA).
  • Plotly.js / Chart.js: interaktive Charts aus JSON, das Gemini per Structured Output liefert.
  • Three.js: 3D-Vorschau (Träger, Platten, Module) – Parameter per Slider.
  • Tailwind (CDN): Layout in Minuten; alles in einer index.html, teilbar per Link oder GitHub Pages.

Fünf Prompts, die den Agenten arbeiten lassen

# 1 – Dashboard-Gerüst
"Baue eine self-contained index.html: Sidebar-Inhaltsverzeichnis, 4 Infoboxen, 1 Plotly-Chart aus dem JSON in data.json. Keine externen Bilder, nur CDN-Scripts."

# 2 – Daten rein
"Lies tallinn_lca.csv (Spalten element, mass_kg, gwp_factor) und erzeuge ein Balkendiagramm GWP je Bauteil, negative Werte grün, Summe im Titel. Code mit Kommentaren."

# 3 – Strukturierte Ausgabe
"Antworte NUR als JSON nach Schema {slide:int, text:str, absolute:bool}. Prüfe diese Folientexte auf Absolut-Behauptungen: …"

# 4 – Selbstkontrolle
"Prüfe deinen Code: Einheiten konsistent? Summe = Σ(mass × factor)? Liste 3 mögliche Fehlerquellen, dann korrigiere."

# 5 – Dokumentation
"Schreibe README.md: Zweck, Start in 3 Schritten, benötigte Keys (nur Namen, keine Werte), Lizenz MIT."

Typische Anfängerfallen

  • Key in die Zelle gepastet → sofort rotieren (AI Studio → Key löschen → neu erstellen).
  • Agent „halluziniert“ Library-Funktionen → Context7/Docs-MCP anschließen, Modell liest echte Doku.
  • Colab-Runtime weg → alles in Drive speichern (drive.mount) oder Notebook in Git.
  • Riesiger Prompt, winziges Ergebnis → Aufgabe zerlegen: Plan → Teilaufgabe → Prüfung, je eigener Run.

Sicherheit

Fünf Regeln, die nicht verhandelbar sind

  1. Keys nie in Chat, Zelle, Repo. Nur .env (in .gitignore), Colab-Secrets, Antigravity-Settings. ${VAR}-Platzhalter in mcp_config.json.
  2. Free Tier = Trainingsdaten. Keine Kundendaten, Pläne oder Passwörter in AI Studio Free.
  3. Least Privilege. GitHub-PAT fine-grained, nur benötigte Repos; MCP-Tools per enabledTools beschneiden; /readonly zuerst.
  4. Plugins lesen, bevor sie laufen. hooks.json und mcp_config.json fremder Plugins prüfen.
  5. Approval an lassen. Antigravity fragt je Tool-Call – das ist das Sicherheitsnetz, nicht die Bremse.
