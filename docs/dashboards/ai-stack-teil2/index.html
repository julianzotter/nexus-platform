01

Anatomie eines Single-File-Dashboards

Ein Web-UI-Dashboard für Ingenieurzwecke braucht fünf Schichten – und alle passen in eine Datei. Der Agent (Antigravity, Claude, Gemini) schreibt sie; du prüfst gegen die Checkliste.

Checkliste vor dem Teilen

  • Öffnet die Datei offline (Doppelklick) ohne Fehler?
  • Nur CDN-Skripte, keine lokalen Pfade, keine API-Keys?
  • Jede Zahl hat Einheit und Quelle (Platzhalter als solche markiert)?
  • Summen stimmen per Hand-Kontrolle (Σ = Masse × Faktor)?
  • SHA256 + Version im Footer oder STATUS.md?

Sandbox-Regeln (Claude-Artifacts)

  • Erlaubte Script-Quellen: cdnjs.cloudflare.com, cdn.jsdelivr.net, unpkg.com, cdn.plot.ly, cdn.tailwindcss.com.
  • fetch() zu fremden Hosts ist blockiert – Gemini-Aufrufe aus dem Browser funktionieren nur lokal/GitHub Pages, nicht im Artifact.
  • Keine Downloads per Script → Copy-Button statt „Speichern unter“.
  • Bilder nur inline (SVG, data:-URI).

MCP-Config-Builder: Server anklicken, JSON kopieren

Die häufigste Hürde beim Einstieg ist eine korrekte mcp_config.json. Hier zusammenklicken, kopieren, nach ~/.gemini/config/mcp_config.json (global) oder <Projekt>/.agents/mcp_config.json (Workspace) legen. Keys bleiben ${VAR}-Platzhalter – echte Werte gehören in .env.

Noch nichts erzeugt.

Nach dem Einfügen

  • App: Agent-Panel → … → MCP Servers → Refresh. CLI: agy starten, /mcp eingeben.
  • Erster Colab-Connect öffnet den Browser-Login; Drive-Scope bewusst freigeben.
  • Developer-Knowledge-Server: Setup laut Codelab (Link #17) – Eintrag hier ist Platzhalter mit serverUrl, bitte gegen Codelab prüfen.

Dasselbe Beispiel wie im Colab-Notebook aus Teil 1 – nur ohne Colab. Werte editieren, Enter, Chart aktualisiert sich. Der Pyodide-Knopf führt dieselbe Rechnung in echtem Python im Browser aus (Download ~10 MB, einmalig).

Platzhalter-Faktoren – durch EPD-Werte ersetzen. Negativ = biogener Kohlenstoffspeicher (A1–A3).

Was hier passiert (Formel vor Zahl)

GWPi = mi · fi  ·  Σ = Σi GWPi. Plausibilität: Vorzeichen je Material (Holz negativ, Beton/Stahl positiv), Größenordnung Stahl ≈ 10× Beton je kg, Einheit kgCO₂e konsistent.

// Kern der Berechnung – identisch in JS und im Pyodide-Snippet
function gwp(rows){ return rows.map(r => ({...r, gwp: r.mass_kg * r.factor})); }
const total = gwp(rows).reduce((s,r)=>s+r.gwp,0);   // Σ-Kontrolle
# Pyodide-Snippet (läuft im Browser, kein Server)
rows = [("CLT wall",12000,-0.60),("Concrete slab",45000,0.11),("Steel beam",3000,1.50),("Glulam beam",6500,-0.55)]
gwp = [(n, m*f) for n,m,f in rows]
total = sum(g for _,g in gwp)
print(gwp, total)
04

Gemini → JSON → Chart: das Datenmuster

Dashboards werden robust, wenn das Modell Daten liefert, nicht Layout. Structured Output zwingt Gemini in ein Schema; die Seite rendert. So bleibt jede Zahl prüfbar.

Schema mit Quellpflicht (Python, google-genai)

from pydantic import BaseModel
from google import genai

class Row(BaseModel):
    element: str
    mass_kg: float
    gwp_factor: float      # kgCO2e/kg, A1-A3
    source: str            # EPD-Nummer oder "PLACEHOLDER"

client = genai.Client()   # GEMINI_API_KEY aus .env / Colab-Secret
r = client.models.generate_content(
    model="gemini-3.5-flash",
    contents=open("stueckliste.txt").read(),
    config={"response_mime_type": "application/json", "response_schema": list[Row]})
open("data.json","w").write(r.text)   # → vom Dashboard geladen

Im Dashboard laden (lokal / GitHub Pages)

<script>
fetch('data.json').then(r=>r.json()).then(rows => {
  const x = rows.map(r=>r.element), y = rows.map(r=>r.mass_kg*r.gwp_factor);
  Plotly.newPlot('chart', [{type:'bar', x, y,
    marker:{color: y.map(v=> v<0 ? '#34d399' : '#c8102e')}}],
    {title:'GWP A1–A3 [kgCO2e] · Σ '+y.reduce((a,b)=>a+b,0).toFixed(0)});
});
</script>

Nie den Gemini-Key in die Seite

  • Ein Browser-Dashboard, das die Gemini-API direkt aufruft, legt den Key offen. Muster: Daten vorab in Colab/Antigravity erzeugen → data.json neben die Seite legen. Für Live-Aufrufe ein kleines Backend (Cloud Run, Firebase Functions) mit Key im Server.
05

Sechs Agenten-Prompts, die Dashboards bauen

Für Antigravity, Claude Code oder Gemini CLI. Jeder Prompt ist ein eigener Run – nie alles in einen werfen.

# P1 · Gerüst
"Erzeuge eine self-contained index.html (deutsch): Sticky-Inhaltsverzeichnis links, 5 Abschnitte, Infoboxen mit Bullets,
Code-Blöcke mit Copy-Button. Nur CDN-Skripte von cdnjs/jsdelivr/plot.ly. Keine Bilder außer inline SVG. Keine Keys."

# P2 · Daten-Schicht
"Lies data.json (Felder element, mass_kg, gwp_factor, source). Rendere Tabelle + Plotly-Balken; negative Werte grün.
Zeige Σ im Titel. Markiere Zeilen mit source == 'PLACEHOLDER' gelb."

# P3 · Interaktion
"Mache Masse und Faktor editierbar; bei Eingabe neu rechnen. Füge 'CSV kopieren' hinzu (Clipboard-API, mit try/catch)."

# P4 · Python im Browser
"Binde Pyodide von cdn.jsdelivr.net/pyodide ein. Button 'Mit Python prüfen' rechnet dieselbe Summe und zeigt Delta zu JS."

# P5 · Selbstprüfung
"Prüfe: Einheiten konsistent? Σ stimmt gegen Handrechnung? Alle externen Skripte auf erlaubten CDNs? Keine fetch() zu fremden Hosts?
Liste Befunde als Tabelle, dann korrigiere."

# P6 · Übergabe
"Schreibe STATUS.md mit YAML-Frontmatter (name, version, status, timestamp, sha256) + LOG-Zeile. Erzeuge SHA256SUMS.txt."

Worauf der Agent achten soll

  • Formel vor Zahl, Einheit an jeder Größe.
  • Platzhalter sichtbar kennzeichnen.
  • Eine Datei, keine Build-Tools.
  • Jede Änderung → neue Version + Hash.

Typische Agent-Fehler

  • Tailwind-Klassen ohne CDN → unsichtbares Layout.
  • alert()/prompt() im Artifact → blockiert.
  • Download-Button → in Sandbox verboten; Copy stattdessen.
  • Halluzinierte Plotly-Optionen → Context7 anschließen.

Deploy & Versionieren: drei Orte, ein Hash

  1. Drive (SSOT): LLM-LOCAL-SSOT/WORK/<datum>_<thema>/index.html + STATUS.md + SHA256SUMS.txt. Nie löschen, nur verschieben.
  2. GitHub (Review-Snapshot): docs/dashboards/<thema>/; Report in WORK/REPORTS/YY_MM_DD_HHMM_THEMA_###_ID##.md. GitHub Pages auf docs/ → öffentliche URL.
  3. Claude-Artifact: privat bis zum Teilen; Republish mit base_version; Hash in Footer eintragen.
  4. Abgleich: Bytes vergleichen (sha256sum), erst dann „gesichert“ melden. Gesendet ≠ bestätigt.

07

Qualität & Sicherheit für Web-UI-Dashboards

Sicherheit

  • Kein API-Key, kein Token, keine PAT im HTML – auch nicht „nur zum Testen“.
  • Nur HTTPS-CDNs; Versionsnummer pinnen (plotly-2.35.2), nicht latest.
  • Clipboard nur aus Klick-Handler, mit try/catch.
  • Drittplugins (Antigravity) vor Install lesen: hooks.json, mcp_config.json.

Qualität

  • Handrechnung einer Zeile im Footer dokumentieren.
  • Platzhalterdaten als solche im Titel kennzeichnen.
  • Faktencheck-Tabelle: geprüft / unbelegt / nicht erreichbar.
  • Barrierearm: Kontrast ≥ 4.5:1, Tabellen mit th, Buttons mit Text.

Kurzcheck Barrierefreiheit & Mobil

  • Sidebar wird unter 900 px zur normalen Liste (hier per @media).
  • Plotly: responsive:true; SVGs mit viewBox, ohne feste Breite.
  • Schrift ≥ 13 px in Code, ≥ 14 px im Fließtext.
